Проект X

Сюжетный экшен с паркуром

На стадии концепта

Город, который никогда не спит. Крыши, которые зовут вперёд. Враги, которые не прощают ошибок. Проект X — динамичный сюжетный экшен, где паркур становится оружием, а каждое решение может стоить жизни.

  • Жанр: Action / Adventure / Parkour
  • Платформы: PC (Windows) — планируются
  • Статус: Концепт / Прототип
  • Команда: Broken Games Studios / CyberBulliyng
Все проекты

Об игре

Вы — выживальщик в мегаполисе будущего. Система следит за каждым движением, а единственный способ остаться свободным — двигаться быстрее, выше и умнее. Паркур здесь не просто механика: это язык, на котором вы разговариваете с городом.

Сюжетные повороты, напряжённые погони, рукопашные стычки и моменты, когда нужно просто остановиться и посмотреть на город с высоты. Проект X сочетает кинематографичный экшен с ощущением свободы движения.

Ваши выборы влияют на отношения с ключевыми персонажами и на то, какой путь выберете в финале.

Текущий статус

На данный момент разработана только система движения. Начата работа над боевой системой. Создаются первые локации и тестируется ощущение скорости и свободы. Визуальный стиль находится на стадии концептов.

На данный момент разработка остановлена. Продолжение начнется после завершения разработки Object Zero. Следите за обновлениями — скоро появятся новые материалы.
